## 4. Decisions & Assumptions
- **Routing**: Install `react-router-dom` for client-side routing (`/` for Catalog/Home, `/courses` for Search/Catalog, `/courses/:slug` for Course Detail, `/courses/:slug/lessons/:lessonSlug` for Lesson view, `/my-learning` for My Learning dashboard).
- **Authentication**: Install `@clerk/clerk-react` and wrap the app in `<ClerkProvider>`. If `VITE_CLERK_PUBLISHABLE_KEY` is not configured or dummy, provide seamless fallback mode for development UI inspection while maintaining full Clerk auth support when configured.
- **Design System Tokens**: Update `tailwind.config.js` with exact tokens from `design-system.png`:
  - Fonts: `font-display` (`Playfair Display, serif`), `font-sans` (`Inter, sans-serif`).
  - Colors: `primary` (`500: #10B981`, `400: #34D399`, `300: #6EE7B7`, `200: #A7F3D0`, `100: #D1FAE5`), `neutral` (`900: #0F172A`, `700: #334155`, `500: #64748B`, `300: #CBD5E1`, `200: #E2E8F0`, `100: #F1F5F9`, `50: #FAFAFC`).
  - Radii and box shadows matching the 4px base scale.
- **Mock Data**: Create comprehensive, realistic mock data matching the courses and lessons shown in the reference designs (`mockCourses.js`, `mockProgress.js`) located in `src/services/mockData.js`.
- **Iconography**: Clean inline SVG icons adhering to the 24x24px grid, 2px stroke width, rounded caps style from `design-system.png` to avoid introducing unauthorized third-party libraries.
- **Video Embed**: Standard YouTube embed component matching `learning-page.png` layout.
- **Responsive Layout**: Mobile-friendly navigation with responsive drawer / hamburger toggle, stacked grid columns on small screens, and a collapsible curriculum sidebar for the lesson page on tablet/mobile screens.
