## 4. Decisions & Assumptions
- **Language**: Pure JavaScript (ES Modules, `"type": "module"`). TypeScript is strictly forbidden per `architecture.md`.
- **Frontend Setup**: Scaffold standard Vite React template (`npx -y create-vite@latest frontend --template react`), then configure the folder hierarchy per `frontend.md` (`src/assets`, `src/components`, `src/pages`, `src/hooks`, `src/services`, `src/utils`).
- **Tailwind CSS Setup**: Install Tailwind CSS v3 with PostCSS and Autoprefixer, creating `tailwind.config.js` and `postcss.config.js` with standard content scanning for `./index.html` and `./src/**/*.{js,jsx}`.
- **Backend Setup**: Initialize `backend/` with standard Node.js Express, supporting ES Modules (`"type": "module"`), installing `express`, `cors`, `dotenv`, and dev dependency `nodemon`. Scaffold directories per `backend.md` (`src/config`, `src/db`, `src/middlewares`, `src/routes`, `src/controllers`, `src/services`, `src/repositories`).
- **Linting & Code Formatting**: Setup ESLint (`eslint`) and Prettier (`prettier`) in both `frontend` and `backend` with `npm run lint` scripts that exit cleanly with code 0.
- **Environment Templates**:
  - `frontend/.env.example`: `VITE_CLERK_PUBLISHABLE_KEY`, `VITE_API_URL`.
  - `backend/.env.example`: `PORT`, `NODE_ENV`, `DATABASE_URL`, `CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, `FRONTEND_URL`.
- **Health Checks**: Backend will provide a lightweight `GET /api/health` endpoint for development and uptime monitoring.
