## Decisions & Assumptions

### 4.1 — Backend: Real Clerk JWT verification
- Install `@clerk/express`.
- Replace the manual Bearer-token logic in `auth.middleware.js` with `@clerk/express`'s `getAuth()`. The dev fallback (placeholder key → use `user_demo_learner`) is preserved by checking whether `CLERK_SECRET_KEY` is a real key.
- `clerkMiddleware()` is mounted globally in `index.js` before routes so `getAuth()` is available on every request.
- `requireAuth` wrapper reads `getAuth(req).userId`; if no userId and no dev fallback → 401.

### 4.2 — Frontend: API service layer
Create thin functions in `src/services/`:
- `src/services/api.js` — base `apiFetch(path, options)` helper; reads `VITE_API_URL`; accepts optional `token` for auth'd requests; catches network errors and returns `null` so callers can fall back to mock data.
- `src/services/courses.js` — `getCourses()`, `getCourseBySlug(slug)`.
- `src/services/lessons.js` — `getLessonBySlug(slug)`.
- `src/services/progress.js` — `getProgress(token)`, `saveProgress(token, payload)`.

Create hooks in `src/hooks/`:
- `src/hooks/useCourse.js` — `useCourse(slug)` → `{ course, loading, error }`.
- `src/hooks/useLesson.js` — `useLesson(slug)` → `{ lesson, loading, error }`.
- `src/hooks/useProgress.js` — `useProgress(lessonId)` → `{ isCompleted, resumeTimestamp, markComplete, saveTimestamp }`.

### 4.3 — Page rewrites (data-only; no visual changes)
- `Home.jsx` — fetch all courses; slice first 4 for featured section.
- `CourseDetail.jsx` — replace `MOCK_COURSES.find()` with `useCourse(slug)`. Show loading + error states using existing Tailwind classes.
- `Lesson.jsx` — replace `MOCK_COURSES` lookup with `useLesson(lessonSlug)` + `useCourse(slug)`. Wire `useProgress(lesson.id)` to "Mark as Complete" button and pass `resumeTimestamp` to `VideoPlayer`. Auto-save every 30 s via `setInterval` in a `useEffect`.
- `MyLearning.jsx` — per `AGENTS.md §6`, purely presentational. Fetch all courses and all progress. Cross-reference on client to build in-progress list.
- `Catalog.jsx` — static/presentational per roadmap; leave unchanged.

### VideoPlayer — resume & periodic save
- `VideoPlayer` gains optional `startTime` (seconds) prop and optional `onTimeUpdate(seconds)` callback.
- `start` parameter is appended to the YouTube embed URL when `startTime > 0`.
- Lesson page polls `onTimeUpdate` every 30 s to fire `saveTimestamp`.

### Dev mode compatibility
When `VITE_API_URL` is not set or the backend is unreachable, API helpers return `null` and hooks fall back to importing from `mockData.js`. This keeps Phase 2 dev workflow intact.

## Security Considerations
- `CLERK_SECRET_KEY` lives only in `backend/.env`. Never in frontend code.
- `VITE_CLERK_PUBLISHABLE_KEY` is the only Clerk key in the frontend bundle.
- `getToken()` called client-side via `useAuth()` hook; JWT sent as `Authorization: Bearer <JWT>`.
- Backend verifies JWT using Clerk SDK against Clerk's JWKS.
- Progress writes remain gated by `requireAuth`. Unauthenticated users can read courses/lessons only.
- Dev fallback: placeholder `CLERK_SECRET_KEY` → backend uses `user_demo_learner`.
